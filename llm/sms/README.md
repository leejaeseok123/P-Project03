# 문자 스미싱 분류

## 데이터

- 학습: Hugging Face `meal-bbang/Korean_message` (19,009건)
  - class 1(일상 대화) + class 3(택배·배송 알림) → 정상(0), class 2 → 사기(1)
  - 숫자·URL·공백 정규화 후 근접 중복 제거 → 14,011건 (정상 6,617 / 사기 7,394)
  - 8:2 층화 분할 (random_state=42)
- 어려운 테스트셋: `data/hard_test.csv` (팀 자체 제작 합성 데이터 100건)
  - 공식 말투 정상 문자 50건 + 친근한 말투 사기 문자 50건

## Baseline: TF-IDF(문자 2~4gram) + Logistic Regression

| 평가                  | Accuracy  | 사기 Recall | 정상 오탐률 |
| --------------------- | --------- | ----------- | ----------- |
| 원본 테스트셋         | 0.998     | 0.996       | 0.000       |
| 중복 제거 후          | 0.996     | 0.993       | 0.001       |
| 글자 깨뜨리기(노이즈) | 0.990     | 0.984       | -           |
| **어려운 테스트셋**   | **0.220** | **0.320**   | **0.880**   |

## 발견한 점

- 기존 데이터셋은 정상 문자가 대부분 일상 채팅이라, 모델이 내용이 아닌 **말투**로 판단함
- 공식 말투 정상 문자(금융 알림, 인증번호)는 거의 전부 사기로 오탐
- 친근한 말투 사기 문자(투자, 로맨스, 지인 사칭)는 대부분 놓침
